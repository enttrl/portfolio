# Структура проекта

- `index.html` — вся HTML-разметка страницы
- `css/global` — переменные, reset и базовые стили
- `css/blocks` — отдельный CSS-файл для каждого блока
- `js/index.js` — рендер карточек проектов и плавный скролл
- `assets/img` — изображения

Верстка рассчитана на экран 1920px и рабочую область 1600px.
